### Compatibility decisions

1. **PostgreSQL major:** keep the newest 16.x patch. A newer major needs backup/restore or `pg_upgrade` planning and rehearsal; replacing a major image tag cannot safely open the existing volume.
2. **WebClient TypeScript:** 6.0.3 is the newest supported by `@astrojs/check`'s `^5 || ^6` peer contract. Docs use 7.0.2. Do not force an unsupported checker/compiler pair just to remove an outdated-package notice.
3. **xUnit runner:** the latest xUnit v3 package family defaults to MTP v2, which rejects the solution's VSTest invocation on .NET 10. Use the supported `xunit.v3.mtp-off` 4.0.1 variant and current VSTest adapter, preserving NUnit/xUnit commands and test discovery.
4. **Existing preview instrumentation:** Process/EF instrumentation have no stable NuGet release. Keep these existing preview dependencies explicit and update to their current RC/beta, rather than silently losing telemetry.
5. **LGTM startup:** Pyroscope failed in a diagnostic container with `--network none`. A normal isolated test container on Docker's bridge started and answered Grafana health. No production data was used.

## Verification

Verification used task-local .NET 10.0.401, Node 26.9.0 and Bun 1.4.2. Existing global runtimes were not overwritten.

- Solution build passed. DAP005 warnings identify installed-but-disabled Dapper.AOT interception; the documentation labels that experiment.
- All five backend suites passed across the solution run and focused reruns: architecture, application, endpoint units, security and disposable PostgreSQL integration. The runner discovered 151 tests in total, none skipped.
- Outbox crash/retry/deduplication and the small EF/Dapper persistence lab passed on PostgreSQL 16.15.
- WebClient typecheck, all 58 tests (including a generated-stylesheet contract), build and audit passed. The stylesheet check covers custom theme utilities and responsive visibility after the Tailwind migration.
- Docs build/audit, all thirteen generated pages, internal routes/fragments/assets, API resource-table contracts and failing-link regression fixtures passed. Social/thumbnail PNGs were regenerated, checked for size/format, inspected and included in the final site build.
- NuGet vulnerability audit including transitive packages and both Bun audits found no reported vulnerabilities at audit time.
- NGINX and Collector configuration validation, all Compose configuration parses and the WebClient container build/health check passed. LGTM answered its health endpoint. Task-owned smoke containers were removed afterward.

No browser rendering/accessibility review, hosted GitHub Actions run, amd64 production image smoke, or deployment was performed. Static/jsdom evidence does not substitute for those checks.
